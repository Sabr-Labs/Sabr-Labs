# Sabr Labs Portfolio Website

A modern portfolio website built with Astro, React (TypeScript), Tailwind CSS, and DaisyUI.

## 🚀 Features

- **Astro Framework** - Fast, modern static site generation
- **React with TypeScript** - Type-safe interactive components
- **Tailwind CSS** - Utility-first CSS framework
- **DaisyUI** - Beautiful UI components
- **Custom Brand Colors** - Professional healthcare-focused color palette

## 📦 Projects Showcased

1. **Birth Your Way** - Empowering platform for expectant mothers
2. **Life Vault** - Secure health records management system

## 🛠️ Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📝 Available Scripts

- `npm run dev` - Start development server at `http://localhost:4321`
- `npm run build` - Build the project for production
- `npm run preview` - Preview the production build locally
